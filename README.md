# 작은 섬의 탐험

돌 사이에 숨은 지뢰를 피해 안전한 땅을 모두 여는 브라우저 지뢰찾기입니다. React와 TypeScript로 만든 정적 앱이며, 계정이나 서버 없이 브라우저 메모리에서 실행됩니다.

## 실행

Node.js **22.12 이상**, npm **10 이상**이 필요합니다.

```sh
npm ci
npm run dev
```

터미널에 표시된 주소를 엽니다. 배포용 파일은 `npm run build`로 `dist/`에 만들고 `npm run preview`로 확인합니다.

## 게임 규칙

- 기본 보드는 10×10이며 행과 열을 각각 5~40으로 바꿀 수 있습니다.
- 왼쪽 클릭으로 칸을 열고 오른쪽 클릭으로 숨은 땅에 깃발을 놓거나 지웁니다. 돌과 깃발이 있는 칸은 열리지 않습니다.
- 첫 번째로 여는 땅은 안전합니다. 인접 땅도 가중치에 따라 일부 보호됩니다.
- 돌은 전체 칸의 약 8%입니다. 지뢰 수는 돌을 제외한 칸 수에 13~17% 범위의 무작위 비율을 곱한 뒤 내림합니다.
- 게임은 첫 클릭 이후 지뢰 배치를 조정해 순수 논리 추론만으로 풀 수 있도록 설계했습니다. 대부분의 게임에서 추측이 필요 없지만 100% 보장은 아닙니다.
- 숫자는 주변 8방향 지뢰 수입니다. 빈칸을 열면 연결된 빈칸과 경계 숫자가 함께 열립니다.
- 안전한 땅을 모두 열면 승리하고 지뢰를 열면 패배합니다. 첫 공개부터 흐른 시간은 종료 시 멈춥니다.
- 새 게임은 보드와 시간을 초기화합니다. 새로고침하면 진행 상황이 사라집니다. 모바일 길게 누르기는 지원하지 않습니다.

## 검증

```sh
npm run check
npm run test:coverage
npx playwright install --with-deps chromium webkit
npm run test:e2e
```

`check`는 포맷·린트·타입·단위/컴포넌트 테스트·빌드를 검사합니다. E2E는 Chromium과 WebKit에서 별도로 실행합니다.

## GitHub Pages

저장소 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 설정합니다. `main`에 반영한 커밋의 CI가 성공하면 Pages 워크플로가 해당 커밋을 빌드·배포합니다. 프로젝트 경로는 저장소 이름으로 자동 설정됩니다. 현재 문서화 단계에서는 실제 배포를 실행하지 않았습니다.
